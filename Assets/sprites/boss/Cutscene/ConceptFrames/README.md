# Church boss cutscene concept frames

These four generated images are visual key-pose studies only, not production animation frames.

They do not share a canvas size, pixel grid, baseline, or stable character proportions. The fourth image is 1536x1024; the others are 1254x1254. They have transparency, but their pixel density and silhouette rendering differ from the game's 64x64 boss sprites. Do not import these as an animation sequence or claim them as a finished cutscene.

The final animation frame must use the existing `Assets/sprites/boss/idle_00.png` unchanged. A production sequence still needs hand-authored, aligned sprite frames that match the game's pixel grid before it can be integrated safely.
