# Практична 9. Git і GitHub

**Мета.** Підготувати репозиторій для Unity проєкту та відтворюваної роботи.

**Структура.** `Assets/` містить сцени, код, графіку й звук; `Packages/` — залежності; `ProjectSettings/` — конфігурацію Unity; `Coursework/2026/` — звіти. `.gitignore` виключає `Library`, `Temp`, `Obj`, `Logs`, збірки й локальні файли IDE. `.meta` файли ресурсів зберігаються, бо вони фіксують GUID посилань Unity.

**Базові команди.** `git clone <url>` отримує проєкт; `git status` показує зміни; `git add` готує їх; `git commit` фіксує версію; `git pull` оновлює локальну гілку; `git push` публікує коміти. Для ізольованої підготовки цього комплекту використано гілку `coursework/2026-practicals` у робочому дереві від репозиторію `stasdbaran/ASH_RISEN`.

**Перевірка публікації.** Стан віддаленого GitHub треба підтвердити фактичним успішним `push`; локальний коміт сам по собі не доводить, що файли вже доступні в мережі. На момент підготовки `fetch` для заданої адреси повернув `Repository not found`, тому цей звіт не стверджує, що завантаження виконано.
