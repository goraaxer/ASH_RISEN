# Ashrisen

Похмура 2D гра в піксельному стилі на Unity 6. Героїня досліджує світ, бореться зі звичайними ворогами та двофазним церковним босом. Проєкт містить головне меню, паузу, локальне збереження, анімації, звук і сцени гри.

## Відкрити проєкт

1. Встановити Unity **6000.6.5f1** з підтримкою 2D.
2. У Unity Hub додати цю папку як проєкт і відкрити її.
3. Дочекатися імпорту пакетів і ресурсів; запустити `Assets/Scenes/MainMenu.unity`.

Сцени збірки записані в `ProjectSettings/EditorBuildSettings.asset`. Папки `Library`, `Temp`, `Obj` та `Logs` створюються локально й не зберігаються в Git.
